# Запуск проекта
## 1. Установка модуел
```bash
npm install
```
```bash
cd client
```
```bash
npm install
```

## 2. Prisma
```bash
npx prisma db pull
```
```bash
npx prisma generate
```
## 3. Запуск Backend

В первом терминале из корневой папки проекта выполни:

```bash
node server.js
```

## 4. Запуск Frontend

Открой второй терминал и выполни:

```bash
cd client
```
```bash
npm start
```
