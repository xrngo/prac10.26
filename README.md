# Запуск проекта
## 1. Установка модуел
```bash
npm install
```
```bash
cd client
```
```bash
npm install
```

## 2. Запуск Backend

В первом терминале из корневой папки проекта выполни:

```bash
node server.js
```

## 3. Запуск Frontend

Открой второй терминал и выполни:

```bash
cd client
```
```bash
npm start
```
